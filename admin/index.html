SETUP CHECKLIST

Первое подключение

Настройте Discord Developer Portal и переменные окружения на VPS/хостинге бота.

  1. 1
    Создайте приложение

    Discord Developer Portal → Applications → New Application.

  2. 2
    Включите Server Members Intent

    В разделе Bot активируйте privileged Gateway Intent для списка участников.

  3. 3
    Заполните переменные окружения

    DISCORD_BOT_TOKEN, DISCORD_CLIENT_ID, DISCORD_GUILD_ID.

  4. 4
    Добавьте бота на сервер

    Дайте доступ к Guilds, Server Members Intent и командам приложений. Не выдавайте Administrator без необходимости.

  5. 5
    Проверьте роли и синхронизацию

    Сверьте роли во вкладке «Роли Discord», затем выполните /family-sync.

!

Токен бота нельзя вводить в это поле или публиковать в архиве. Изменение токена выполняется в секретах хостинга/.env с последующим перезапуском процесса.

IMPORTANT

Перед публикацией

01

Смените пароль администратора
Используйте отдельную учётную запись Supabase Auth с надёжным паролем и app_metadata.role = admin.

02

Не выкладывайте `.env`
Файл `.env` относится только к Discord-боту и не должен попадать в Git. В нём хранятся токен бота и серверный Supabase key.

03

Включите TLS
Включите GitHub Pages HTTPS. Хостинг бота отдельно должен хранить секреты в переменных окружения.

04

Проверяйте Supabase RLS
Используйте SQL-файл `sql/002_verify_security.sql` после миграции.
